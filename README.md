# TEPPALA VAHINI Portfolio

A dark luxury portfolio for a data analyst and machine learning specialist, built with Next.js.

## Features
- Modern luxury dark aesthetic
- Tailored for data analytics and machine learning
- Responsive layout for desktop and mobile
- Sections for About, Skills, Projects, and Contact

## Tech stack
- Next.js
- React
- TypeScript

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000
